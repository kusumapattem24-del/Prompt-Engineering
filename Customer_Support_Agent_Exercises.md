**Task:** Define a friendly, calm, solution-oriented persona and the required 4-stage flow.

### Answer - Setup Steps

- Define flow: Greet -> Identify issue -> Provide solution -> Confirm resolution.

## Exercise 2 - Gather Support Knowledge Files

### Answer - Setup Steps

## Exercise 3 - Build the Instruction Block with Escalation Guardrails

**Task:** Write instructions enforcing persona, flow, and escalation for critical/unresolved issues.

### Answer - Setup Steps
- Define Role: Customer Support Agent (Level 1).
- Add escalation triggers and prohibited commitments (legal advice, financial commitments, out-of-scope promises).
- Save as instruction_block.md.

### Answer - Setup Steps
