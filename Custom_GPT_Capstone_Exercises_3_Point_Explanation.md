# Custom GPT Capstone Exercises - 3-Point Explanation

## Exercise 1 - Consolidate Prior Deliverables

1. We collect all work from Topics 1-9, including the use case, instructions, persona, flow, knowledge files, tool rules, guardrails, testing, and evaluation documents.
2. We review the files to identify duplicate, overlapping, or conflicting instructions that could affect the final GPT.
3. We organize and finalize the deliverables so they can be combined into one complete and consistent Custom GPT.

## Exercise 2 - Build the Complete Custom GPT

1. We create the final Custom GPT and combine the approved role, persona, scope, conversation flow, tool rules, and other instructions into one instruction block.
2. We upload the finalized knowledge files and enable all required tools or capabilities.
3. We verify that all guardrails and safety rules are included so the GPT behaves correctly and securely.

## Exercise 3 - Run End-to-End Testing

1. We test the completed GPT with a normal request, an edge case, and a guardrail scenario.
2. We rerun the previous test checklist to make sure combining all components has not introduced new issues or conflicts.
3. We record the results in capstone_test_log.md and confirm that the GPT is accurate, consistent, and ready for use.

## Exercise 4 - Prepare and Record the Demo

1. We prepare a short demo script explaining the problem solved, target users, important design decisions, and key GPT features.
2. We record a 4-6 minute walkthrough showing how the Custom GPT works with a practical example.
3. We make the recording shareable and organize all final files inside the custom-gpt-capstone folder for submission.
