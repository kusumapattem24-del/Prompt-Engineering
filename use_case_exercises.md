# Custom GPT Use Case - Exercises 1-4

## Exercise 1 - Identify the Real-World Problem

**Task:** Identify a specific, recurring, real-world problem within your organization or a chosen domain that could be solved by a Custom GPT.

### Answer - Setup Steps

1. Open a document titled `use_case_document.md`.
2. List 2-3 candidate problems and select the one with the highest frequency, clarity, and feasibility.
3. Confirm the chosen problem is specific (not generic) and tied to an identifiable user group.

---

## Exercise 2 - Define GPT Name and Target Users

**Task:** Draft a descriptive GPT Name and clearly identify the Target Users (primary and secondary).

### Answer - Setup Steps

1. In ChatGPT, run a naming brainstorm prompt to generate 5 candidate names; select the clearest one.
2. Document primary users (who interacts most) and secondary users (who benefits indirectly).
3. Save both under `## GPT Name` and `## Target Users` headings.

---

## Exercise 3 - Write the Problem Statement

**Task:** Write a clear, specific problem statement explaining the cause, impact, and current gap.

### Answer - Setup Steps

1. Draft 2-3 sentences describing the problem.
2. Refine using ChatGPT for clarity and specificity.
3. Save under `## Problem Statement`.

---

## Exercise 4 - Define Expected Outcomes and Validate Feasibility

**Task:** Define 3-5 measurable expected outcomes and validate the use case against Clarity, Relevance, and Feasibility.

### Answer - Setup Steps

1. List measurable outcomes, such as percentage reduction in repetitive queries or improvement in response time.
2. Review the full document against the three evaluation criteria - Clarity, Relevance, and Feasibility - and revise any weak section.
3. Compile the final one-page use case document.

---

## Final Deliverable

The completed `use_case_document.md` should contain the following sections:

- `## GPT Name`
- `## Target Users`
- `## Problem Statement`
- `## Expected Outcomes`
- Feasibility validation based on Clarity, Relevance, and Feasibility
