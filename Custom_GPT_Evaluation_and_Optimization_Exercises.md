# Custom GPT Evaluation and Optimization Exercises

## Exercise 1 - Define Scoring Metrics

**Task:** Define clear scoring rubrics for Accuracy, Clarity, and Consistency.

### Answer - Setup Steps
- Create evaluation_sheet.md.
- Define a 1-5 (or similar) scale for each metric with concrete criteria per score level.

## Exercise 2 - Score at Least 10 Responses

**Task:** Run at least 10 varied queries and score each response using the defined rubric.

### Answer - Setup Steps
- Build an evaluation table: Query, Response Summary, Accuracy, Clarity, Consistency, Notes.
- Run and score 10+ responses.

## Exercise 3 - Identify Weak Areas

**Task:** Analyze scores to identify the lowest-performing metric or recurring issue.

### Answer - Setup Steps
- Review the evaluation sheet for patterns.
- Summarize under ## Weak Areas Identified.

## Exercise 4 - Optimize and Document

**Task:** Apply targeted optimizations to instructions based on weak areas and document the results.

### Answer - Setup Steps
- Apply minimal, targeted edits addressing the identified weaknesses.
- Create optimization_summary.md documenting weak areas, changes made, and expected impact.
- Re-score a sample of previously weak responses to confirm improvement.
