# Custom GPT Persona Exercises - 3-Point Explanation

## Exercise 1 - Define Persona Attributes

1. We define a Persona Name that represents the identity and purpose of the Custom GPT.
2. We specify the Expertise Level so the GPT knows how knowledgeable and detailed its responses should be.
3. We define the Communication Style, such as professional, friendly, simple, or step-by-step, to keep responses consistent.

## Exercise 2 - Define Allowed and Restricted Behaviors

1. Allowed Behaviors define what the GPT is permitted to help users with within its intended scope.
2. Restricted Behaviors define what the GPT must not do, especially for unsafe, sensitive, or out-of-scope requests.
3. These rules help the GPT provide safe, relevant, and consistent responses while staying within its defined boundaries.

## Exercise 3 - Add Persona Rules to Instructions

1. We add the persona attributes and behavior rules to the existing GPT instruction block.
2. This ensures the GPT follows the same role, communication style, expertise level, and behavioral boundaries in every conversation.
3. After updating the instruction block, we save the GPT configuration so the new persona rules are applied.

## Exercise 4 - Test and Compile Sample Conversations

1. We test the GPT with different types of queries, including emotional, technical, and vague questions.
2. We verify that the GPT maintains the same persona, tone, and behavior across different situations.
3. We document the test conversations in sample_conversations.md to demonstrate that the persona works consistently.
