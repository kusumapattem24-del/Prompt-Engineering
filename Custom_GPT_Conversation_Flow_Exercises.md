# Custom GPT Conversation Flow Exercises

## Exercise 1 - Map the First-Time User Flow

**Task:** Create a step-by-step flow (or diagram) for a first-time user, covering greeting, context, clarification, execution, and confirmation.

### Answer - Setup Steps
- Create `flow_design.md`.
- Draft the first-time user flow with all four core stages represented.
- Save under `## First-Time User Flow`.

## Exercise 2 - Map the Returning User Flow

**Task:** Create a shorter, more direct flow for a returning user.

### Answer - Setup Steps
- Adjust the first-time flow to skip unnecessary orientation.
- Save under `## Returning User Flow`.

## Exercise 3 - Define Clarification Questions

**Task:** List clarification questions the GPT should ask when user intent is unclear.

### Answer - Setup Steps
- List 3-5 clarification questions relevant to the GPT's use case.
- Save under `## Clarification Questions`.

## Exercise 4 - Integrate and Test the Flow

**Task:** Add flow logic to the GPT's instructions and test with incomplete or ambiguous inputs.

### Answer - Setup Steps
- Add a `## Conversation Flow` section to the instruction block.
- Submit 3-4 incomplete or ambiguous test messages.
- Record observations in `test_observations.md`.
